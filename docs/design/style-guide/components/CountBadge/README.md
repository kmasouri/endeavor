# CountBadge

The red number that says "look here", used the same way everywhere.

- `notify` ground, `notify-ink` number, `badge` type, `radius-full`, 22px tall, at least 22px wide.
- Used for unread conversations and Approvals. Nothing else in the app is red.
- An unread conversation also turns its name bold and `text-100`.
- Over 99, show "99+".
