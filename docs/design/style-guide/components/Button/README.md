# Button

Buttons say exactly what happens, and there is one primary button per card or form.

- **Primary**: `accent` ground, `accent-ink` text, semibold. The main action: Send, Read it, Allow once, Resume.
- **Secondary**: transparent, `border-200` border, `text-100` text. Every other action: Accept, Ask for changes, Pause, Stop.
- **Icon**: transparent, `text-200` icon, 36px square, always with an accessible name (Reply, Copy, Attach a document).
- Height `control` (36px), corners `radius-md`. Focus shows a 2px `link` outline.
