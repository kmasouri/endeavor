# StatusChip

A small labelled chip for a state that matters, never an icon on its own.

- **Approved / done**: `success` text and icon on `success-bg`. "Approved Draft 2".
- **Waiting on someone**: `text-200` on `bg-200` with a `border-100` border and a clock. "Waiting for Reviewer to answer · 40 s". When it's waiting on you, use `waiting` text instead.
- 24 to 28px tall, `radius-full` or `radius-sm`, `meta` or `caption` type.
